# Irrigation Controller (Android)

A starter Android app for managing an irrigation system. It includes:
- Pump start/stop control.
- Multiple irrigation zones with enable/disable toggles.
- Adjustable watering duration per zone.
- Sample soil moisture readings.

## Build

1. Open the project in Android Studio (Hedgehog+).
2. Let Gradle sync.
3. Run on an emulator or Android device.

## Notes

This is a starter UI-first implementation intended to be connected to real hardware or an API.
